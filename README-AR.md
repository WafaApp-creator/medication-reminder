# بناء تطبيق «مذكّر الأدوية» الأصلي (تنبيهات والتطبيق مغلق)

هذا المشروع يحوّل التطبيق إلى تطبيق أندرويد حقيقي يجدول إشعارات محلية لكل جرعة، فتصل في موعدها حتى لو كان التطبيق مغلقاً. البناء يتم تلقائياً على خوادم GitHub المجانية، دون Android Studio.

## الخطوات (من الحاسوب أسهل)
1. أنشئ حساباً مجانياً على github.com، ثم **New repository** باسم `med-reminder` (اجعله Private إن أردت).
2. فُكّ ضغط الملف المرفق، ثم من صفحة المستودع: **Add file ← Upload files**، واسحب **كل** محتويات المجلد (بما فيه مجلد `.github`)، ثم **Commit changes**.
   - إن لم يظهر مجلد `.github` (مجلدات النقطة مخفية أحياناً): اختر **Add file ← Create new file**، واكتب الاسم `.github/workflows/android.yml` والصق فيه محتوى الملف `android.yml` من المجلد.
3. افتح تبويب **Actions**، اختر **Build APK**، ثم **Run workflow**. انتظر 5 إلى 10 دقائق حتى تظهر علامة ✓ خضراء.
4. افتح التشغيل المكتمل، ومن **Artifacts** نزّل `medication-reminder-apk`، وفُكّ ضغطه لتحصل على `app-debug.apk`.
5. انقل الملف إلى هاتفك وثبّته (اسمح بالتثبيت من هذا المصدر عند الطلب).

## أول تشغيل
- اسمح بـ**الإشعارات**، وبـ**المنبّهات والتذكيرات** إن طُلب منك.
- من إعدادات الهاتف ← البطارية ← التطبيق: اختر **بدون قيود** (بعض الهواتف مثل شاومي وأوبو وسامسونج توقف التطبيقات في الخلفية).
- أضف دواءً وانتظر موعده للتجربة. تُحدَّث الإشعارات تلقائياً عند أي إضافة أو تعديل أو حذف.

## ملاحظات
- النسخة الناتجة «تجريبية» (debug) تصلح للاستخدام الشخصي. للنشر على Google Play ستحتاج نسخة موقّعة (AAB)، ويمكن تجهيزها لاحقاً.
- لم أستطع بناء الملف أو تجربته على هاتف حقيقي من بيئتي. اختبرت منطق الجدولة فقط، فجرّب على هاتفك وأخبرني بالنتيجة.
